# TG Anon Send Bot

Минималистичный и простой Telegram-бот для приема и отправки анонимных сообщений по персональной ссылке.

## Особенности

- **Динамические ссылки** — генерация ссылки с `username` или `id` пользователя.
- **Поддержка всех типов контента** — текст, фото, видео, голосовые сообщения, стикеры.
- **Анонимный диалог - Реплей** — возможность отвечать на анонимные сообщения прямо из бота.
- **Защита от спама** — блокировка пользователей
- **Профиль и настройки** — статистика отправленных/полученных сообщений и чекбокс приема анонимок.

## Запуск

1. Установить зависимости:
```bash
pip install aiogram
```

2. Указать ваш токен в `projectdie.py`:
```python
TOKEN = "TOKEN"
```

3. Запуск бота:
```bash
python projectdie.py
```
